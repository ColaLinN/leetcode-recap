# 验证记录

此文件记录交付时实际执行的验证，日后修改代码或题库需重新运行相关检查。

## 验收项目

| 范围 | 验证方式 |
| --- | --- |
| 全部博客专题与素材 | 检查导入数量、文件路径、章节关联与本地图像请求 |
| 每章精选题目 | 检查章节引用、题目去重、2–4 道题与题面/模板/测试完整性 |
| 真实 Python 判题 | Docker 中运行所有参考解与完整测试集 |
| 正确与错误反馈 | 正确解、错误解、语法错误、死循环、输出洪泛、不可用运行时 |
| 复杂结构 | 链表、环链表、二叉树、原地修改与设计类连续操作 |
| 个人记录 | 草稿、复习标记、提交历史、通过进度、恢复与继续上次 |
| 分屏交互 | 桌面左右布局、拖动分隔线、窄屏布局与编辑器加载 |
| 页面内容 | 题面/笔记/题解切换、Markdown 图像与公式、章节导航 |
| 本地部署 | 安装、构建、启动、停止、健康接口和本机访问 |
| Git 与文档 | 阶段性提交、干净工作区、可执行 Quickstart 和备份说明 |

## 可重复命令

```sh
.venv/bin/python -m pytest backend/tests -q
npm --prefix frontend run build
./scripts/start.sh
curl http://127.0.0.1:8765/api/health
./scripts/stop.sh
```

全题库回归与最终浏览器检查结果在集成测试完成后记录。
